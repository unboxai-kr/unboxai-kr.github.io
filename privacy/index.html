개인정보처리방침

SNS Studio와 UNBOX AI 링크 모음이 YouTube API로 받은 데이터를 어떻게 다루는지 설명합니다.

시행일 2026년 10월 3일

1. 운영자와 대상

SNS Studio는 유튜브 채널 「언박스 AI」(@unboxai_kr)를 운영하는 개인 크리에이터가 자기 채널의 쇼츠를 만들고 관리하려고 쓰는 영상 제작 도구입니다. 운영자 한 사람의 컴퓨터에서만 실행되며, 다른 사람에게 서비스로 제공하지 않습니다. 이 방침은 SNS Studio와 이 웹사이트(unboxai-kr.github.io)에 적용됩니다.

2. YouTube API 서비스 사용

SNS Studio는 YouTube API 서비스(YouTube Data API)를 사용합니다. SNS Studio를 사용하면 YouTube 서비스 약관에 동의하는 것으로 봅니다. Google이 데이터를 처리하는 방식은 Google 개인정보처리방침(http://www.google.com/policies/privacy)에서 확인할 수 있습니다.

SNS Studio가 YouTube에서 하는 일은 다음과 같습니다.

  • 영상 올리기: 운영자가 만든 영상을 운영자 본인의 채널에 올립니다. 제목, 설명, 태그, 공개 범위(공개, 일부 공개, 비공개)는 올리기 화면에서 운영자가 확인하고 고른 그대로 보냅니다.
  • 댓글 답글: 운영자 채널의 댓글을 불러와 보여 주고, 운영자가 답글마다 「올리기」를 누를 때만 답글을 올립니다. 운영자가 특정 영상에 직접 켠 경우에만 그 영상의 새 댓글에 사용법 페이지 링크를 담은 답글을 자동으로 올립니다(기본은 꺼짐, 시간당 20개와 하루 40개 이하, 언제든 멈출 수 있음).
  • 채널 확인: 연결된 채널의 이름과 ID를 읽어 어느 채널에 연결됐는지 보여 줍니다.
  • 주제 찾기: 공개된 인기 쇼츠 목록(제목, 채널 이름, 썸네일, 조회수 등)을 보여 주고, YouTube 링크와 YouTube 임베드 플레이어로 보게 합니다. YouTube 영상을 내려받지 않습니다.

3. 접근하고 저장하는 정보

4. 정보의 이용과 제공

YouTube에서 받은 데이터는 위 기능을 운영자에게 제공하는 데만 씁니다. 팔거나 빌려주지 않고, 광고에 쓰지 않으며, 다른 출처의 데이터와 합치지 않습니다. YouTube 데이터가 앱 밖으로 나가는 경우는 다음뿐입니다.

  • Google(YouTube): API 요청은 YouTube API 서비스로 보냅니다.
  • OpenAI(Codex): 운영자가 요청할 때 운영자 본인의 Codex 계정으로 글을 보내 초안을 만듭니다. 공개 영상의 메타데이터와 댓글 글(작성자 이름 제외)은 영상 요약, 댓글 분류, 답글 초안에 쓰이고, 자동 링크 답글을 켠 영상에서는 인사말을 위해 댓글 작성자의 표시 이름도 보냅니다. OpenAI는 자사 약관과 개인정보처리방침에 따라 처리합니다.
  • 영상 제작에 쓰는 다른 서비스(스톡 영상 검색 Pexels와 Pixabay, 음성 합성, 운영자가 연결한 경우 Instagram 게시)에는 YouTube에서 받은 데이터를 보내지 않습니다.
  • 앱에서 YouTube 임베드 플레이어로 영상을 재생하면 YouTube가 Google 개인정보처리방침에 따라 데이터를 수집할 수 있습니다.

5. 보관 기간과 삭제

  • 30일 규칙: 앱이 켜져 있는 동안 12시간마다 확인해, YouTube에서 받은 지 25일이 지난 데이터는 새로 받고, 28일까지 새로 받지 못한 데이터는 지웁니다. 검색 결과와 영상 정보 캐시는 대부분 몇 시간 안에 만료됩니다.
  • 연결 해제: 앱 설정의 「연결 해제」를 누르면 Google에서 토큰을 폐기하고 토큰, 댓글함, 답글 기록, 저장된 채널 정보를 바로 지웁니다. 앱으로 올린 영상 기록은 7일 안에 다시 연결하지 않으면 지웁니다.
  • 모두 지우기: 앱 설정의 「유튜브 데이터 모두 지우기」를 누르면 접근 권한을 폐기하고, 앱이 저장한 YouTube 데이터(올린 영상 기록 포함)를 바로 모두 지웁니다. 프로젝트를 지우면 그 프로젝트의 데이터도 함께 지워집니다.
  • 권한 확인: 앱은 12시간마다 접근 권한이 아직 유효한지 확인하고, 권한이 폐기되거나 만료되면 그 권한으로 받은 데이터를 7일 안에 지웁니다.
  • 앱에서 데이터를 지워도 YouTube에 있는 영상과 댓글은 지워지지 않습니다. YouTube의 데이터는 YouTube 또는 YouTube 스튜디오에서 지워야 합니다.

6. 접근 권한 철회

앱의 「연결 해제」와 별도로, Google 보안 설정 페이지(https://security.google.com/settings/security/permissions)에서 언제든 SNS Studio의 접근 권한을 철회할 수 있습니다.

7. 안전성 확보 조치

앱은 같은 컴퓨터(127.0.0.1)에서 온 접속만 받습니다. API 요청은 HTTPS로 보내고, 토큰과 키 파일은 컴퓨터 사용자 계정만 읽을 수 있습니다. 위 4번의 경우 말고는 데이터가 운영자 컴퓨터 밖으로 나가지 않습니다.

8. 방침의 변경

앱이 데이터를 새로운 방식으로 쓰게 되면 이 페이지를 고치고 시행일을 바꿉니다.

Privacy Policy

English version. Effective October 3, 2026.

1. Who we are

SNS Studio is a video production tool used by the individual creator who runs the YouTube channel 언박스 AI (UNBOX AI, @unboxai_kr) to make and manage Shorts for that channel. It runs only on the operator's own computer and is not offered to anyone else as a service. This policy applies to SNS Studio and to this website (unboxai-kr.github.io).

2. Use of YouTube API Services

SNS Studio uses YouTube API Services (the YouTube Data API). By using SNS Studio, you agree to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy (http://www.google.com/policies/privacy).

SNS Studio does the following with YouTube:

  • Upload: uploads a video the operator produced to the operator's own channel. The title, description, tags and privacy status (public, unlisted or private) are sent exactly as the operator reviews and chooses them on the upload screen.
  • Comment replies: loads comments on the operator's channel and posts a reply only when the operator clicks "Post" for that reply. Only if the operator turns it on for a specific video, the app automatically replies to new comments on that video with a link to its guide page (off by default, at most 20 per hour and 40 per day, can be paused at any time).
  • Channel check: reads the connected channel's name and ID to show which channel is connected.
  • Topic research: shows lists of popular public Shorts (title, channel name, thumbnail, view count and similar) with a link to YouTube and the YouTube embedded player. YouTube videos are never downloaded.

3. Information we access and store

All data is stored only in the app's data folder on the operator's computer. There is no separate server, database or user account run by the operator.

4. How information is used and shared

Data obtained from YouTube is used only to provide the features above to the operator. It is not sold or rented, not used for advertising, and not combined with data from other sources. YouTube data leaves the app only in these cases:

  • Google (YouTube): API requests are sent to YouTube API Services.
  • OpenAI (Codex): when the operator asks, the app sends text to the operator's own Codex account to create drafts. Public video metadata and comment text (without author names) are used to summarize a video, classify comments and draft replies. On videos where the optional link auto-reply is turned on, the commenter's display name is also sent so the reply can greet them. OpenAI processes this data under its own terms and privacy policy.
  • Other services used to produce videos (stock footage search on Pexels and Pixabay, text-to-speech, and Instagram publishing if the operator connects an account) never receive data obtained from YouTube.
  • When a video is played in the app with the YouTube embedded player, YouTube may collect data as described in the Google Privacy Policy.

5. Retention and deletion

  • 30-day rule: while the app is running it checks every 12 hours. YouTube data older than 25 days is refreshed from YouTube, and anything that could not be refreshed is deleted by day 28. Cached search results and video details usually expire within hours.
  • Disconnect: "Disconnect" in the app settings revokes the token with Google and immediately deletes the token, the comment inbox, the reply history and stored channel information. Upload records are deleted if the account is not reconnected within 7 days.
  • Delete all: "Delete all YouTube data" in the app settings revokes access and immediately deletes all YouTube data stored by the app, including upload records. Deleting a project also deletes its data.
  • Authorization check: every 12 hours the app checks that its access is still valid. If access was revoked or has expired, data obtained with it is deleted within 7 days.
  • Deleting data in the app does not delete anything on YouTube. To delete videos or comments on YouTube, use YouTube or YouTube Studio.

6. Revoking access

Besides "Disconnect" in the app, you can revoke SNS Studio's access to your Google account at any time on the Google security settings page (https://security.google.com/settings/security/permissions).

7. Security

The app accepts connections only from the same computer (127.0.0.1). API requests use HTTPS, and token and key files are readable only by the computer's user account. Except as described in section 4, data does not leave the operator's computer.

8. Changes to this policy

If the app starts using data in a new way, this page and its effective date are updated.
