SNS Studio 소개

「언박스 AI」 채널 운영자가 자기 컴퓨터에서만 쓰는 쇼츠 제작 도구입니다. 공개 웹 서비스가 아니어서 로그인 주소가 없습니다.

무엇을 하나요

새로 나온 AI 도구를 1분 쇼츠로 소개하는 영상을 만듭니다. 자료 정리, 대본, 음성, 자막, 화면을 만들어 영상으로 완성하고, 운영자가 제목과 설명과 공개 범위를 확인한 뒤 자기 채널에 올립니다.

YouTube API로 하는 일

  • 운영자 본인 채널에 쇼츠 올리기 (videos.insert). 올리기 화면에서 제목, 설명, 태그, 공개 범위를 확인하고 운영자가 직접 누릅니다.
  • 운영자 채널의 댓글 읽기와 답글 달기 (commentThreads.list, comments.insert). 답글은 운영자가 하나씩 확인하고 올립니다. 영상마다 켜는 링크 자동 답글은 기본으로 꺼져 있습니다.
  • 연결된 채널 이름 확인 (channels.list).
  • 주제를 찾으려고 공개 인기 쇼츠 목록 보기 (search.list, videos.list, playlistItems.list). 영상은 내려받지 않고 YouTube 링크와 임베드 플레이어로만 봅니다.

데이터

모든 데이터는 운영자 컴퓨터에만 저장하고, YouTube에서 받은 데이터는 30일 안에 새로 받거나 지웁니다. 자세한 내용은 개인정보처리방침에 있습니다. 문의: https://www.instagram.com/unboxai_kr/

About SNS Studio

What it is

SNS Studio is a Shorts production tool that the operator of the YouTube channel 언박스 AI (UNBOX AI) runs only on their own computer. It is not a public web service, so there is no login page. It researches new AI tools, writes a script, generates voice, captions and visuals, renders the video, and lets the operator upload it to their own channel after reviewing the title, description and privacy status.

How it uses YouTube API Services

  • Uploads Shorts to the operator's own channel (videos.insert). The operator reviews title, description, tags and privacy status on the upload screen and starts every upload.
  • Reads comments on the operator's channel and posts replies the operator approves one by one (commentThreads.list, comments.insert). An optional per-video link reply is off by default.
  • Shows the connected channel name (channels.list).
  • Shows lists of popular public Shorts for topic research (search.list, videos.list, playlistItems.list). Videos are never downloaded; they are opened on YouTube or in the embedded player.

Data

All data stays on the operator's computer, and data obtained from YouTube is refreshed or deleted within 30 days. See the Privacy Policy for details. Contact: https://www.instagram.com/unboxai_kr/
