시행일 2026년 10월 3일

1. 대상

이 약관은 SNS Studio와 이 웹사이트(unboxai-kr.github.io)에 적용됩니다. SNS Studio는 유튜브 채널 「언박스 AI」 운영자가 자기 채널을 위해 자기 컴퓨터에서만 쓰는 영상 제작 도구이며, 다른 사람에게 판매하거나 배포하지 않습니다.

2. YouTube 서비스 약관

SNS Studio는 YouTube API 서비스를 사용합니다. SNS Studio를 사용하면 YouTube 서비스 약관(https://www.youtube.com/t/terms)을 따르는 데 동의하는 것입니다. 개인정보는 SNS Studio 개인정보처리방침과 Google 개인정보처리방침에 따라 처리됩니다.

3. 올리는 콘텐츠

올리는 영상과 제목, 설명, 태그는 올리는 사람이 책임집니다. 올리기 화면의 안내처럼, 올리는 콘텐츠는 YouTube 서비스 약관과 YouTube 커뮤니티 가이드를 지켜야 하고 다른 사람의 저작권이나 개인정보를 침해하면 안 됩니다. 앱은 제목, 설명, 공개 범위를 사용자가 확인하고 고른 그대로 보냅니다.

4. 사용 규칙

  • 스팸, 오해를 부르는 제목과 설명과 태그, 조회수나 좋아요나 댓글을 인위로 늘리는 일에 쓰지 않습니다.
  • YouTube의 제한이나 정책을 피하는 용도로 쓰지 않습니다.
  • 영상 업로드와 답글은 사용자가 내용을 확인하고 실행합니다. 자동 링크 답글은 사용자가 영상마다 직접 켠 경우에만 동작합니다.
